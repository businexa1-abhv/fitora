# Archive

Unused scaffolding preserved for future reuse. Not part of the active pnpm workspace.

## Contents

- `packages/` — stub/shared packages never imported by apps (`api-client`, `auth`, `ui`, `constants`, `design-system`, `hooks`, `theme`, `utils`, `validation`)
- `backend/` — microservice stubs superseded by `apps/api`
- `database/` — stale Prisma stub; canonical schema is `apps/api/prisma`

Do not delete without product confirmation. Re-home into `packages/` or `backend/` when implementing.
